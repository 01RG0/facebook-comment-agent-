== ZERNIO API -- KEY ENDPOINTS ==

Base URL: https://zernio.com/api/v1
Auth: Authorization: Bearer {ZERNIO_API_KEY}

### 1. Facebook Connect (OAuth)
GET /v1/connect/facebook
  Query params: profileId (required), redirect_url (your callback URL)
  Returns JSON: { authUrl: 'https://...' }   <- redirect user here

After Facebook auth, Zernio redirects to your redirect_url with:
  ?connected=facebook&profileId=X&accountId=Y&username=Z

### 2. Disconnect an account
DELETE /v1/accounts/{accountId}
  Auth: Bearer
  Response: { success: true }

### 3. Register Zernio webhook
POST /v1/webhooks/settings
  Body: {
    name: string,
    url: string,
    secret: string,
    events: ['comment.received'],
    isActive: true
  }
  Response: { success: true, webhook: { _id: string } }

### 4. Webhook event payload (comment.received)
Headers:
  X-Zernio-Signature = lowercase hex HMAC-SHA256 of raw body keyed by ZERNIO_WEBHOOK_SECRET
  X-Zernio-Event = 'comment.received'
  X-Zernio-Event-Id = stable event UUID

Payload shape:
{
  id: string,
  event: 'comment.received',
  timestamp: string,
  comment: {
    id: string,
    platformPostId: string,
    platform: 'facebook' | 'instagram' | ...,
    text: string,
    isReply: boolean,
    parentCommentId: string | null,
    author: {
      id: string,
      name?: string,
      username?: string,
      isOwnAccount?: boolean
    },
    createdAt: string
  },
  post: { platformPostId: string },
  account: {
    id: string,
    platform: string,
    username: string
  }
}

### 5. Send private DM reply to commenter
POST /v1/inbox/comments/{platformPostId}/{commentId}/private-reply
  Body: {
    accountId: string,   <- pages.zernio_account_id
    message: string
  }
  Response: { status: 'success', messageId: string }
  Error 400 with details.privateReplyConsumed = true means already replied -- do not retry

### 6. Post public comment reply
POST /v1/inbox/comments/{postId}
  Body: {
    accountId: string,
    message: string,
    commentId: string
  }
  Response: { success: true, data: { commentId: string } }
